# EduTrack – Student Record Management Dashboard

## Project Overview

EduTrack is a modern and user-friendly Student Record Management Dashboard developed using HTML, CSS, and JavaScript. It helps users manage student information, monitor academic performance, and view student records through a simple and interactive dashboard.

The dashboard displays important statistics such as total students enrolled, average marks, highest scorer, and number of students passed. It also provides features to search, filter, sort, add, edit, and delete student records.

## Objectives

* To develop a simple and interactive student record management system.
* To display student academic information in a dashboard format.
* To make searching, filtering, and sorting student records easier.
* To calculate and display student performance statistics.
* To provide an easy-to-use interface for managing student details.

## Features

* **Dashboard Overview:** Displays total enrolled students, average marks, highest scorer, and students passed.
* **Student Records:** Displays student details in a structured table.
* **Search Functionality:** Search for students using the available search feature.
* **Filter Options:** Filter student records by department, year, and status.
* **Sorting:** Sort student records using the available sorting options.
* **Add Student:** Add new student records.
* **Edit Student:** Update existing student details.
* **Delete Student:** Remove individual student records.
* **Student Profile:** View additional information about a selected student.
* **CSV Export:** Export student records to a CSV file.
* **Theme Toggle:** Switch between the available dashboard themes.
* **Local Storage:** Retain supported student data in the browser.
* **Responsive Interface:** Provides a clean and organized dashboard layout.

## Technologies Used

* **HTML5** – Structures the dashboard webpage.
* **CSS3** – Styles the dashboard and its components.
* **JavaScript** – Implements dashboard functionality and user interactions.
* **Browser Local Storage** – Stores supported student data locally.
* **Google Fonts** – Provides typography for the interface.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Double-click `index.html` to open it in a web browser.
5. Use the dashboard to explore and manage student records.

No additional compiler or backend server is required to run this front-end project.

## Usage

1. Open the dashboard in your browser.
2. View the student statistics displayed at the top.
3. Search for students using the search bar.
4. Apply department, year, or status filters.
5. Sort student records using the available options.
6. Add new students or edit and delete existing records.
7. Export student information using the CSV export option.
8. Use the theme toggle to change the dashboard appearance.

## Deployment

This project can be hosted using GitHub Pages.

1. Upload the project files to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages** from the sidebar.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)` folder.
6. Click **Save** and wait for the website to be published.

## Limitations

This is a front-end project. Student records stored using browser Local Storage are generally limited to the browser and device where they were saved. A shared database, authentication, and server-side security are not included unless implemented separately.

## Conclusion

EduTrack provides a simple and interactive solution for managing student records and viewing academic performance. By combining HTML, CSS, and JavaScript, the project demonstrates how a web-based dashboard can organize student information and simplify common record management tasks. It can be further enhanced with database integration, authentication, analytics, and additional academic management features.
